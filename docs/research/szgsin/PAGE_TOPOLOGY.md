# 页面拓扑（PAGE TOPOLOGY）

> 数据范围：`routes.json`、`ROUTE_MAP.md` 与 `docs/design-references/szgsin/` 中现有截图。本文描述页面族和共享骨架，不代表页面实现或内容已完成。

## 1. 路由规模与结论

本次抓取共记录 **217 个公开 HTML 地址**，但视觉实现不需要 217 套页面。路由可以归并为少量可复用的页面族：

| 抓取类型 | 数量 | 说明 |
| --- | ---: | --- |
| 首页 | 1 | 单页全屏分屏首页 |
| 独立单页 | 7 | 公司介绍、发展历程、联系我们、技术体系等；含无 `.html` 别名 |
| 文章/栏目列表 | 14 | 业务、新闻、荣誉、证书等栏目；其中 1 条抓取状态为 0 |
| 分页地址 | 35 | 与栏目列表共用布局，只改变数据页码 |
| 内容详情 | 156 | 共用 `/article/detail/{id}.html` 路由模式；需要按所属栏目选择详情表现 |
| 下载列表 | 2 | 同一技术资料栏目的一组别名 |
| 其他 | 2 | Cloudflare 邮件保护 404、原站搜索 500，不属于正常内容页 |

状态统计：211 条记录为 HTTP 200；`/`、`/article/gsry.html`、`/article/detail/143.html`、`/article/detail/173.html` 的抓取状态为 0；另有 1 条 404 和 1 条 500。状态 0 代表此次抓取未取得有效状态，不能据此认定路由不存在。

**核心判断：**静态复刻可由约 8 个视觉骨架驱动，分页和 156 个详情地址通过数据生成；URL 数量主要来自内容量，而不是布局数量。

## 3. 全站共享结构

### 3.1 全局页头

截图中的所有页面使用同一桌面页头：

- 左侧 GSIN 标志。
- 中部五项主导航：首页、关于金鑫、业务板块、科技创新、新闻中心。
- 当前主栏目为整块绿色高亮。
- 右侧为 `EN/中` 语言入口和搜索图标。
- 首页各分屏持续保留同一页头；内页页头下接栏目横幅。

### 3.2 内页公共上半部

除首页外，代表截图均呈现以下顺序：

1. 全局页头。
2. 大幅栏目横幅/封面区。
3. 横幅底部的灰色面包屑条。
4. 白底二级栏目标签栏，当前项使用绿色块和下方小三角。
5. 页面主体。

现有截图中横幅经常只显示大面积空白或局部图像，说明抓取时部分背景资源未完整绘制；复刻时不能把这块空白误判为设计本身。

### 3.3 右侧悬浮工具条

首页和内页均出现固定在右侧的绿色工具条：

- 顶部圆形关闭按钮。
- QQ/客服入口。
- 二维码入口。
- 电话入口。
- 邮件入口。
- 返回顶部。

这是跨页面的独立共享组件，不属于任一内容页面主体。

### 3.4 全局页脚

内页及首页末屏共享双层页脚：

- 上层：主导航复刻与“分享”图标组。
- 下层：品牌标志、公司名、备案/公网安备信息、全国热线 `0755-84078008`。
- 顶部以绿色细线与正文分隔。

首页前几个全屏分屏不显示页脚，仅在最后内容段落收束时出现。

## 4. 页面族

### A. 全屏首页

**代表路由：** `/`

**截图证据：** `home-page1-desktop.png` 至 `home-page5-desktop.png`，以及 `home-desktop.png`、`home-tablet.png`、`home-mobile.png`。

**共享结构：**

- 固定页头。
- 左侧垂直圆点分屏导航。
- 右侧悬浮工具条。
- 主体采用整视口分屏，而不是普通内页的横幅、面包屑、二级导航结构。

**分屏内容：**

1. 项目展示：全屏项目图、左侧深色参数面板、前后切换按钮、右侧竖排项目名。
2. 公司介绍：左侧大幅视频/图片与播放按钮，右侧标题、简介、查看更多和四组经营数字。
3. 业务板块：三块纵向视觉面板，叠加 `+` 和业务名称。
4. 新闻中心：左侧大图重点新闻，右侧多条新闻摘要和查看更多。
5. 新闻延续及页脚收束：末段继续新闻内容并显示完整全局页脚。

首页是唯一需要专用页面骨架的路由。

## 6. 推荐的静态模板边界

为了维持 1:1 视觉并减少重复，页面拓扑建议对应以下模板边界：

1. `HomePage`：首页五段全屏结构。
2. `InnerShell`：页头、横幅、面包屑、二级导航、右侧工具条和页脚。
3. `AboutContentPage`：公司介绍/普通图文单页。
4. `ContactPage`：联系表单与联系方式双栏。
5. `ProjectListPage`：五类业务项目列表与分页。
6. `ProjectDetailPage`：项目图、参数和推荐案例。
7. `InnovationPage` / `DownloadListPage`：技术体系介绍与技术资料列表。
8. `NewsListPage` / `NewsDetailPage`：新闻列表及文章详情。

其中 `InnerShell` 是所有内页的共用外壳；分页不是新模板；路由别名不是新模板；156 条详情需先按内容类型分流，再进入相应详情模板。

## 7. 截图证据与限制

- 首页的桌面五个分屏已有独立截图，可直接作为首页分段验收基准。
- 关于、业务、科技创新、新闻和项目详情均有桌面截图；关于、业务、科技创新、新闻、项目详情另有名为 tablet/mobile 的截图。
- 除首页 `home-mobile.png` 为 390px 宽外，多数名为 `mobile` 或 `tablet` 的内页截图实际像素宽度均为 1220px，不能单凭文件名视为 390px/768px 响应式基准。
- 多张内页截图出现背景图、卡片图或主体媒体只加载局部的情况。拓扑可据此确认容器和层级，但具体媒体尺寸与裁切仍需重新采集完整状态。
- `routes.json` 的 title/heading 信息大多为空或为统一站点标题，不能用于判断 156 条详情的实际内容类型。
